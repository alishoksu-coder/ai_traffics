07 · Machine Learning Pipeline

Алдын ала өңдеу → белгілер → модель → метрика

1

Time features: hour, weekday, peak-time, holiday/event context.

2

Scaling: neural network training тұрақтылығы үшін normalization.

3

Windowing: соңғы N уақыт қадамы → келесі 30/60 минут болжамы.

X[t-N:t] = {speed, congestion, weather, time}

ŷ[t+h] = fθ(X[t-N:t])

Loss = MAE / RMSE
